# iOS 题宝库(Interview Vault)v2

帮助 iOS 开发者**巩固面试知识、加强记忆、查漏补缺**的本地优先备考系统。
**252 道**高频面试题 / 17 个分类 / **117 道选择题**,支持自建题目、笔记沉淀、限时模拟面试、备考倒计时,**装到手机上断网也能刷**。

## 快速开始

无需构建、无需依赖:

```bash
cd ios-interview-hub
python3 -m http.server 8000
# 打开 http://localhost:8000
```

也可直接双击 `index.html`(功能完整,仅离线安装不可用 —— 浏览器要求 Service Worker 运行在 https 或 localhost)。

学习数据全部保存在浏览器本地,**不联网、不上传**。

### 装到手机上离线用

1. 把整个目录部署到任意 **HTTPS** 站点(GitHub Pages / Vercel / 自建皆可,纯静态无后端)
2. 手机 Safari 打开 → 分享 → **添加到主屏幕**
3. 之后地铁无网照样刷题,学习记录本地保存

> 本地验证过:断网后整页重载,252 题、自建内容、笔记、进度全部可用。

## 数据语义(重要)

数据分两类,**重置时行为不同**:

- **学习记录**(进度、错题、收藏、打卡、测验与模拟面历史)→ 「重置学习记录」会清空
- **用户内容**(自建题目、笔记、备考计划、设置)→ **永远保留**,只能通过「删除我的内容」单独清除

**导入备份**时:学习记录整片替换;**笔记与自建题按条目合并**,不会覆盖本机已有的内容(跨设备导入安全)。

## 添加题目

**方式一(推荐)**:直接在 App 里「我的题目 → 新建」,支持 Markdown 预览、选择题、追问。

**方式二**:改 `js/data/` 下的分类文件,追加对象即可。题目 id 由分类 + 题干哈希生成,**插入任意位置不影响既有学习记录**:

```js
{
  t: '你的问题',
  lv: 2, fq: 3,                    // lv 难度 1-3,fq 考频 1-3
  opt: ['选项A', '选项B', '选项C', '选项D'], ans: 0,  // 可选:选择题
  tags: ['标签'],
  key: ['速记要点 1', '速记要点 2'],
  a: `答案(markdown,支持表格/代码块/列表)`,
  deep: `面试官追问的深挖内容(可选,模拟面试会用它自动追问)`,
},
```

> ⚠️ 答案是 JS 模板字符串,里面的 markdown 反引号**必须转义成 `` \` ``**。裸反引号会劈断字符串且 `node --check` 查不出来 —— 改完务必跑 `node check-data.js`。

## 开发

```bash
node check-data.js          # 题库完整性校验(id 唯一、选项合法、反引号劈断检测)
./bump-version.sh 2.0.4     # 改完 JS/CSS 后同步版本号(index/tests/sw/设置页)
open http://localhost:8000/tests.html   # 39 项单元测试
```

**改完 JS/CSS 必须 bump 版本号**,否则浏览器与 Service Worker 会继续用旧文件。版本号散落在 4 处,`bump-version.sh` 是唯一入口。

页面加载异常或版本卡住时:设置 → 离线 → **清除离线缓存**(一键注销 SW 并重载)。

### 架构约定

- 零构建、零依赖:`index.html` 按序加载全局脚本 `version → util → md → icons → data → data/* → store → router → ui → views/* → app`
- 视图共享 `#view` 容器:事件绑定用 `el._bound_<name>` 哨兵,且每个 `onClick` 开头必须有 `if (App.router.current !== '<name>') return;` 路由守卫
- `sw.js`:`index.html` 走网络优先(防旧壳锁死),带 `?v=` 的资源走缓存优先,activate 清理非当前版本缓存
